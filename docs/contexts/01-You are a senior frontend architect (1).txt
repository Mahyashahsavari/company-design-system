You are a senior frontend architect and TypeScript engineer.

Build a production-ready frontend Design System monorepo from scratch.

The goal is to create a centralized Company Design System that can be used as the shared UI foundation for multiple React/Vite applications.

The Design System must be based on Mantine, use Turborepo + pnpm for monorepo management, and use Storybook as the main visual documentation and component exploration environment.

The repository must include two real example consumer applications:

- monosuite-assets-management
- monosuite-war-room

These applications are reference/consumer projects that prove the Design System can be consumed by multiple products.

Do not stop at scaffolding. Configure everything and make sure the complete repository works end-to-end.

Company Design System

# 7. @company/ui

Create:

packages/ui/

This is the main public UI package.

It should wrap or extend Mantine where appropriate.

Important architectural rule:

Application developers should import UI components from:

@company/ui

and NOT directly from:

@mantine/core

For example:

import { Button, Card, TextInput } from "@company/ui";

instead of:

import { Button } from "@mantine/core";

Mantine is an implementation detail behind the Company Design System.

However, do NOT blindly wrap every Mantine component.

If a Mantine component already satisfies our requirements, re-export it from @company/ui.

Create custom wrappers only when we need:

- company-specific defaults
- company-specific variants
- custom styling
- custom behavior
- standardized API
- additional functionality
- custom documentation

Prefer simple solutions.

Do not over-engineer.
